# Security Policy

If you discover a security vulnerability or sensitive security issue related to this repository, please report it privately to:

**[thedevorger.alekrythae.dev@gmail.com](mailto:thedevorger.alekrythae.dev@gmail.com)**

Please include, where possible:

- A description of the issue
- Steps to reproduce it
- The affected component or version
- Any relevant logs, screenshots, or technical details

Please do not publicly disclose the vulnerability before it has been reviewed and appropriate action has been taken.

Thank you for helping keep TheDEvorger projects secure.
